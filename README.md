# dome

Dome is a collection of helpful binaries that happen to pair well with agents.

## Apps

| App | What it does |
| --- | --- |
| [`dome`](apps/dome) | Installs and removes apps from this suite. |
| [`clipme`](apps/clipme) | Copies exact text from WSL to the Windows clipboard. |
| [`squid`](apps/squid) | Turns Markdown with embedded SQL into reports and pages. |
